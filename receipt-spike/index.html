⚙ 設定

キーはこの端末のブラウザ内にのみ保存されます（このアプリにサーバーはありません）。レシート画像は分析のときだけ、あなたのキーで Anthropic API に直接送信されます。それ以外に外部へ送るものはありません。
🔐 おすすめ運用: このアプリ専用のAPIキーを発行し、Console 側で支出上限を低く設定しておく（万一漏れても被害がその上限で止まる・いつでも失効できる）。

📤 期間を指定して書き出し
